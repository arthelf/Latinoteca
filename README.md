# Latinoteca 📚

Um acervo de empréstimo online de livros latino-americanos. O projeto busca não só preservar, mas também mostrar o quão importante é a cultura da literatura do nosso continente.

## Sobre o projeto

Latinoteca é um site criado com meios de prática e aprendizado, não um projeto sério e funcional no mundo real. Tanto que nenhuma segurança é realmente prezada nos dados do projeto, por limitação de conteúdo visto no curso.
A função de back-end é exercida pelo Supabase (PostgreSQL).

## Linguagens e tecnologias utilizadas

Linguagens:
- **HTML5**
- **CSS3**
- **JavaScript**
- **SQL**

Tecnologias:
- **Supabase (PostgreSQL)**
- **API REST via fetch**

## Funcionalidades

- Ler, alterar, cadastrar e deletar informações do banco de dados através da interface de usuário;
- Salvar os dados inseridos de um usuário logado no localStorage do navegador.
